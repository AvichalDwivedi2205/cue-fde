# Cue logo v1

The symbol is a C with its top end broken off into a green dot. The dot is the customer's signal. The arc is the loop Cue closes: reproduce, fix, verify, reply. The gap between them is where a person approves.

| File | Use |
|---|---|
| `cue-logo.svg` | Primary horizontal lockup on light backgrounds |
| `cue-logo-on-dark.svg` | Same lockup on dark backgrounds (white, bright green dot) |
| `cue-logo-stacked.svg` | Stacked lockup for square spaces |
| `cue-logo-mono-black.svg`, `cue-logo-mono-white.svg` | One-colour versions for print, embossing, green fields |
| `cue-symbol*.svg` | Symbol alone |
| `cue-wordmark.svg` | Wordmark alone. It is drawn, not typeset; never retype it. |
| `cue-app-icon.svg` | App icon on the dark tile (default), plus `-signal` (green tile) and `-light` versions |
| `favicon.svg` | Favicon version for 32 px and below: bigger mark, heavier stroke |
| `png/` | App icon at 1024/512/180 px, favicons at 32/16 px, logo at 2000 px wide (transparent) |

**Colours:**
- Ink `#14181A`
- Night `#111513`
- Paper `#F6F6F3`
- Signal `#17A05E` (the dot on light backgrounds)
- Signal Bright `#3DD68C` (the dot on dark backgrounds)
- Deep Green `#17633F` (green fields under a white logo)

**Rules:**
- Clear space: keep half the symbol's height clear on every side.
- Minimum size: lockup 96 px wide; symbol 16 px. Below 32 px, use `favicon.svg`.
- The dot is the only green. Never move it, recolour the C, close the gap or rotate the mark.
