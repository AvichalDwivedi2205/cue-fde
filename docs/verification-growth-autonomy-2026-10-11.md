# Growth autonomy correction — October 11, 2026

The user found that Growth displayed a prominent manual source-capture form and required manual qualification. The selected source was from March 2019. The earlier configured-workspace acceptance covered real discovery and the separately operated reply journey, but did not establish the expected automatic discovery → qualification → draft → review experience. This report corrects that gap and limits the completion claim to observed evidence.

## Resulting behavior

- Start/resume enables the existing bounded hosted campaign and resumes unfinished sources. New captures queue qualification atomically; an eligible match queues drafting; a valid committed draft creates an exact review in Cue. These steps run through the hosted workpool without operator stage clicks.
- Growth is the primary page flow: agent status, Start/Pause, automatic queue and replies ready for review. Manual qualification and the interim manual drafting button are removed. Optional assisted import is collapsed within Campaigns only, preserving its actual provenance.
- Source dates must fall within the current seven-day window. Historical/future/invalid dates are rejected with the original source evidence retained. Reviewed/published recommendations cannot be overwritten by a later qualification-policy refresh. Qualification and draft completion retain the capability-version fence.
- Discovery respects the existing daily limit, UTC day reset, cursor, cooldown, bounded lease and official provider connection. Start checks the current free-credit balance with the existing $1.10 reserve requirement. No budget reset, limit increase, purchase, new credential scope or fabricated source was used for this correction.
- Replies still require exact human review and publication. Automatic preparation does not automatically approve, send a Slack message or publish a post. When review has no Slack delivery, the UI accurately identifies Cue as the review surface.
